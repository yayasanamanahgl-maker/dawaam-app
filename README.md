# DAWAAM

Teman Istiqamah Setiap Hari.

**Mulai dari yang mampu. Jaga yang sudah tumbuh.**

DAWAAM adalah aplikasi pencatatan ibadah personal. Versi ini menyimpan data ibadah di browser perangkat (IndexedDB), mendukung cadangan/pemulihan JSON, dan menggunakan service worker untuk akses offline setelah dibuka melalui HTTPS.

Catatan: notifikasi Android di latar belakang dan sinkronisasi akun belum tersedia. Jangan mengunggah file cadangan ibadah pribadi ke repository publik ini.
